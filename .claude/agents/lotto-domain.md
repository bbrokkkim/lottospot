# 동행복권 도메인 지식

## 회차 계산
- 1회차 기준일: 2002년 12월 07일 (토요일)
- 매주 토요일 추첨, 23시 이후 결과 반영
- 현재 회차 ≈ (오늘 - 2002-12-07) / 7 + 1

## 등수 구조
- 1등: 6개 번호 일치
- 2등: 5개 + 보너스 번호 일치
- 당첨 횟수는 API/크롤링 응답에 포함 — 직접 카운팅 불필요

## 데이터 소스 (우선순위 순)
1. 공공데이터포털 (data.go.kr) — "복권판매점" 검색. 공식 데이터, 안정적
2. 동행복권 크롤링 — 폴백용. 비공식 엔드포인트라 사용 전 생존 여부 직접 확인 필수
